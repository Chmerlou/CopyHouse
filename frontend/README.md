## CopyHouse frontend

Адаптивный интерфейс сервиса поиска копицентров.

### Локальный запуск

```bash
npm run dev
```

Проверки: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.

### Запуск с бэкендом

Запусти бэкенд из ветки `dev-backend` на порту 3000. Во фронтенде запусти:

```bash
COPYHOUSE_DATA_SOURCE=live COPYHOUSE_API_BASE_URL=http://localhost:3000/api npm run dev -- --port 3001
```

Открой фронтенд по адресу `http://localhost:3001`. Без `COPYHOUSE_DATA_SOURCE=live`
фронтенд использует моки. Для проверки заказа нужна активная одобренная точка
с тарифами в городе тестового клиента.

В режиме `live` владелец меняет тарифы своих точек в разделе «Панель точки» (`/provider`).
Администратор входит через ту же форму и попадает в раздел «Заявки» (`/admin/print-points`).
Чтобы проверить одобрение, нужна точка в статусе `PENDING`. Демо-аккаунты и готовые точки для локального запуска создаёт `prisma/seed.js` бэкенда.
